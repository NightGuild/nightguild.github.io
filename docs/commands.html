Command reference

Use this page to document every public command, its arguments, permissions, and examples.

This is a template, not a complete command list. Verify every command against the current command files before publishing.

Command format

For each command, include its name, purpose, permissions, arguments, cooldowns, and a working example.

/command-name [required argument] [optional argument]

FIELDWHAT TO INCLUDE
CommandExact registered command name.
DescriptionOne sentence explaining its purpose.
ArgumentsOptions, valid values, and whether required.
PermissionsWho can use it and role requirements.
CooldownCooldown duration, if any.
ExampleA working example from the real implementation.
