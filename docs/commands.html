How commands work

A quick guide to running NightGuildBot commands in Discord and understanding the options each command asks for.

Private botCommands are only available in servers where the private bot has been installed by its owner.

Slash commands

  1. Go to a text channel where the bot can respond.
  2. Type / and choose NightGuildBot from Discord's app command list.
  3. Choose the command you want. Discord will show the options it accepts.
  4. Fill in required fields, review your input, and press Enter or click Submit.
  5. Read the bot's response. Some commands may return buttons, menus, or follow-up steps.

Reading command options

Required fieldsMust be filled in before the command can be submitted.
Optional fieldsCan be left empty if you want the default behaviour.
ChoicesSelect one of the values Discord provides in the menu.
PermissionsSome commands are limited to staff, administrators, or feature owners.

Prefix commands

Some deployments may also support text-prefix commands. The prefix can be configured, so check the bot's help response or ask the server administrator for the current prefix. Do not assume a prefix if it has not been confirmed.

Command examples

Illustrative syntax only

/command-name required-option optional-option

This is a format example, not a real registered NightGuildBot command. Use Discord's command picker for the actual command names and options.

Why a command may not appear

  • The command has not been registered or deployed yet.
  • Your account does not have permission to use it.
  • The bot is not installed in the server you are checking.
  • The command is only enabled in a specific test server or channel.
This reference intentionally explains how to use Discord commands without guessing command names. The live slash-command picker is the accurate source for the current command list.
