Using commands

NightGuildBot uses Discord commands to access its features. Here's how to find them and understand what Discord is asking you for.

Private botThe commands only appear in servers where NightGuildBot has been installed.

Finding a command

  1. Open a channel where the bot is allowed to respond.
  2. Type /. Discord will show the slash-command picker.
  3. Find NightGuildBot in the app list, then choose the command you want.
  4. Fill in any required options and submit it.
  5. Read the reply. Some features use buttons or menus for the next step.

What the options mean

RequiredYou need to fill this in before Discord will let you submit the command.
OptionalYou can leave this blank if you don't need to change the default.
ChoicesPick one of the options Discord shows you.
PermissionsSome commands are only available to the server staff, guild owner or certain members.

Why isn't a command showing up?

  • The bot may not be installed in that server.
  • The command may be limited to a particular role or channel.
  • A recent command change may not have been registered yet.
  • The feature may not be enabled in the current private build.

About command names

I’m keeping this page focused on how to use the commands rather than listing names that might already be out of date. The Discord picker is the accurate list for the version you're using. Select a command there to see its description and options before running it.

If a command fails, copy the error message and let the server administrator know. Please don't share bot tokens, passwords or other private credentials when reporting an issue.
