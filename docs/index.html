How to use these docs

Start with the getting-started guide, then open the page for the feature you want to use. The command picker inside Discord is the most reliable place to see commands currently registered and available to your account.

NightGuildBot is actively developed. Exact options, cooldowns, permissions, and feature availability can change between versions. If a page and the running bot disagree, trust the bot's current response.
