About these pages

I'm writing the docs alongside the bot, so some details will change. I haven't listed command names or exact prices where I can't guarantee they're current. For the exact commands available to you, type / in a server where the bot is installed and look through the NightGuildBot command list.

If something in a guide doesn't match what the bot is doing, trust the bot's current response and let me know what page needs fixing.
