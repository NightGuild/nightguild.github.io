FEATURE GUIDE

Music

Listen together in a Discord voice channel using the music features enabled in your bot deployment.

Basic playback

Join a voice channel, use the play command with a supported URL or search query, then manage playback using the available queue commands.

Supported sources

Provider support depends on the installed resolver and availability. A provider URL may identify a track and find a playable match rather than stream audio directly from that provider.
