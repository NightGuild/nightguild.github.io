Guilds

The guild system is designed to let players organize into groups and work toward shared progression.

What guilds are for

A guild gives a group of members a shared identity and a place to build progress together. Depending on the current build, guild features may include membership management, shared progression, and a dedicated forum post.

Before creating or joining

  • Check whether a guild already exists for your group.
  • Read any name or membership rules shown by the bot.
  • Make sure you understand which actions are limited to the guild owner or staff.

Guild management

Use the guild-related commands visible in Discord's slash-command picker. Select a command to see the options currently supported by the running version. Management buttons shown on a guild post may provide additional actions.

Shared progression and posts

If your server has guild progression enabled, check the guild's own response or post for its current status. Avoid creating duplicate guilds or posts if something appears missing; ask a bot administrator to check it first.

Guild command names, limits, costs, and permissions are version-dependent. Use the live command picker and bot responses for exact instructions.
