FEATURE GUIDE

Guild system

Guilds help members organize, contribute, and progress together.

Creating a guild

Use the guild creation command shown in Discord’s command picker. Your server may enforce name rules, message requirements, ownership limits, or cooldowns.

Guild posts

Guilds may have a dedicated forum post. If a post is missing, contact an authorized bot administrator rather than repeatedly creating a new guild.
