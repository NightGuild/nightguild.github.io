FEATURE GUIDE

Text games

NightGuildBot includes its own take on chat-based collecting and game progression, inspired by familiar animal-collecting bots.

Collecting and hunting

Use the text-game commands shown in Discord's command picker to discover the available activities. Read each result carefully; it may tell you what you found and what you can do next.

Inventory and collection

Where enabled, profile and inventory features help you review collected animals, items, and other progress. A collection view can help you see what you have already discovered.

Battles and progression

Some builds may include battles, teams, items, or other progression systems. Check the options and descriptions provided by the current bot before starting an activity or spending resources.

NightGuildBot is its own project; it does not necessarily include every feature from other bots. Exact game mechanics and command names depend on the current build.
