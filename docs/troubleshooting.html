Troubleshooting

Try these checks when a NightGuildBot command or feature does not behave as expected.

A command does not appear

  • Confirm NightGuildBot is installed in the server you are using.
  • Check the slash-command picker again and search for the bot's name.
  • Some commands are restricted by role, channel, or server.
  • A new command may not have been registered or deployed yet.

The bot does not respond

  • Check whether the bot is online.
  • Make sure the bot can view the channel and send messages there.
  • Check whether the command is only allowed in a different channel.
  • Try again later if the bot is restarting or undergoing maintenance.

Music does not play

  • Join the voice channel first.
  • Check that the bot can connect and speak in that channel.
  • Try a different supported source if the current link cannot be resolved.
  • Music providers and audio dependencies may be temporarily unavailable.

Still stuck?

Note the command you tried, the channel, the approximate time, and the exact error message. Share those details with the server administrator or bot owner. Do not post private tokens or credentials.

NightGuildBot is currently a private project. Support and access are managed by the owner; there is no public invite or public support promise at this stage.
