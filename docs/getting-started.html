Getting started

Learn how to find commands, understand their options, and get help when something does not work.

Private botNightGuildBot is not currently open for public invitations. This guide is for people who already have access to its test server.

1. Find the bot in your server

Open a server where NightGuildBot is already installed. Check that the bot is online. If it is offline, commands will not run until the bot is started again.

2. Find available slash commands

  1. Open a text channel
    Choose a channel where you are allowed to use bot commands.
  2. Type /
    Discord opens its slash-command picker. Look for NightGuildBot in the app list and browse the commands visible to your account.
  3. Select a command
    Discord displays the command's required and optional fields. Fill in the required fields, then submit it.
  4. Read the response
    The bot may reply publicly or with an ephemeral message visible only to you. Follow any buttons or menus it provides.

3. Understand command arguments

Example format (illustrative only)

/example required-option optional-option

Required option: You must provide it before Discord lets you submit.

Optional option: You can leave it blank unless you need that setting.

The example above explains Discord's command format; it is not a real NightGuildBot command.

4. Explore a feature

  • Guilds — teams and shared progression.
  • Economy & progression — currency, rewards, and upgrades.
  • Fishing — catches and collections.
  • Music — voice playback and queues.
  • Text games — collecting and game systems.

5. If a command is missing or fails

Check that the bot is online, that you are using a channel where commands are allowed, and that your account has the required permissions. Also check Troubleshooting.

The slash-command picker shows commands registered and available to you. Some commands may be restricted to administrators, staff, guild owners, or specific test users.
