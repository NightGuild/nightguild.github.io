Getting started

A quick route from joining the server to using NightGuildBot's features.

1. Make sure the bot is available

NightGuildBot must be online in your Discord server, and you need permission to use the commands you want. Some features may be restricted to staff or guild owners.

2. Open the command list

Use Discord's slash-command picker to see commands available to your account. Text commands, where enabled, use the configured bot prefix.

3. Choose a feature

  • Guild guide for team features.
  • Economy and progression for currency and upgrades.
  • Fishing for rods and catches.
  • Music for playback and queues.
Requirements, cooldowns, and permissions can vary by server configuration. Use the bot's current responses as the source of truth.

4. Need help?

Check troubleshooting, then ask your server's staff if the issue persists.
