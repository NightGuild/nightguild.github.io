Terms of use

The ground rules for using NightGuildBot and reading this website.

Last updated: 13 November 2026

NightGuildBot is a private, independently developed project. Access is limited and may be changed while the bot is being tested and developed.

Access to the bot

NightGuildBot is not currently open for public invitations. You may only use it if the developer has provided access or installed it in a server you are part of. Please don't redistribute private invite links, credentials or access in a way the developer hasn't approved.

Using the bot responsibly

Use the bot in a way that follows Discord's Terms of Service and Community Guidelines, as well as the rules of the server you're in. Don't use it to spam, harass people, disrupt a server, exploit bugs, interfere with the bot's operation or attempt to access data that isn't yours.

Development and availability

This is an ongoing project, not a guaranteed service. Features may be changed, paused, reset or removed. The bot or website may be unavailable while updates are being made, and saved progress could be affected by bugs, maintenance or changes to the database. There is no promise of uninterrupted service or permanent data storage.

Server permissions

Server owners and administrators are responsible for choosing where the bot is installed and what permissions it receives. Give it only the permissions needed for the features you want to use, and make sure members know when a bot feature posts information in a shared channel.

Third-party platforms

NightGuildBot relies on Discord and the website is hosted using GitHub Pages. Those services are separate from this project and have their own terms, policies and availability. NightGuildBot is not sponsored by or affiliated with Discord or GitHub.

Changes or suspension of access

The developer may change the bot, limit access or suspend use if needed to protect the project, its users or the infrastructure it runs on. If you spot a bug or security issue, report it to the person who gave you access rather than trying to exploit it.

Changes to these terms

These terms may be updated as the project develops. The latest version will be posted here. If you don't agree with an update, stop using the bot.

Contact

For questions about these terms, contact the developer through the person or server that gave you access to NightGuildBot.
