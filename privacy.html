Privacy policy

A straightforward explanation of the information NightGuildBot needs to run and how it is used.

Last updated: 13 November 2026

NightGuildBot is currently a private project. This policy covers the bot and this website as they are intended to operate. The developer should keep it in sync with the actual hosting, database, logs and integrations as those change.

What information is involved?

When you use NightGuildBot, Discord sends the bot the information needed to handle your command or interaction. Depending on the feature, that can include your Discord user ID, the server and channel IDs, your chosen command options, and your Discord display name.

To keep features working between sessions, the bot may store game data linked to your Discord user ID. That can include your balance, inventory, fishing collection, guild membership and other progress or settings you create while using the bot.

Why is it used?

The bot uses this information to respond to commands, save your progress, run guild features, keep the economy consistent and troubleshoot problems. Technical logs may also contain information about errors and bot activity so the developer can investigate issues.

Where does it go?

Bot data is handled by Discord and by the machine or hosting service running NightGuildBot. The website is hosted through GitHub Pages. Those services may process technical information under their own privacy policies. If the bot adds another integration, this page should be updated to explain what it receives.

Who can see it?

Information shown in a public Discord reply or guild post can be seen by people who have access to that server or channel. The developer may access stored bot data and technical logs when maintaining the project or investigating a problem. Don't put passwords, payment details or other sensitive personal information into bot commands.

How long is information kept?

Game data is kept while it is needed to provide the bot's features. Technical logs and backups may be kept for a different period depending on the hosting setup. The exact retention periods depend on the current deployment and should be reviewed whenever the hosting or database setup changes.

Your choices and data requests

You can stop interacting with the bot at any time. If you want to ask about data linked to your Discord account or request that it be deleted, contact the person who gave you access to the private bot. The developer may need your Discord user ID to identify the relevant records. Some information may remain in backups for a limited period or where it must be retained for security or operational reasons.

Third-party services

Discord is required for the bot to work. The website is served by GitHub Pages. Other providers may be involved when optional integrations are enabled; their involvement depends on the features running at the time. Each provider has its own terms and privacy policy.

Changes to this page

If the bot starts collecting new types of information or changes where it stores data, this page should be updated. The latest version will always be published here.

Contact

For a privacy question, contact the developer through the person or server that gave you access to NightGuildBot. Please don't post private credentials or sensitive information in a public channel.

NightGuildBot is an independent project and is not affiliated with or operated by Discord.
